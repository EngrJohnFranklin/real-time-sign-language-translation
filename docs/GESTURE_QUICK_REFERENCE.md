# Ten-Word Sign Reference

## Dataset Labels

Use these exact folder and model labels when recording templates:

| Display word | Dataset label |
|---|---|
| Good | `good` |
| Hello | `hello` |
| I Love You | `i_love_you` |
| Love | `love` |
| Me | `me` |
| No | `no` |
| Quiet | `quiet` |
| Sorry | `sorry` |
| Thank You | `thank_you` |
| Yes | `yes` |

The handshape descriptions for these words are not validated in this guide.
Consult [PSL_WORDS_REFERENCE.md](PSL_WORDS_REFERENCE.md) and verify every sign
against an authoritative FSL reference before collection.

Record templates using `scripts/collect_word_templates.py`. Keep the sign
steady, fully visible, and well-lit for each take.
