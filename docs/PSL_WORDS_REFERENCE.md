# Filipino Sign Language Word Reference Template

> Warning: This document is currently unverified. The entries below identify
> the active static-word labels but do not validate their sign descriptions.
> Cross-check them against an authoritative FSL source, such as SLLAP, before
> production use.

This document is a template for verified Filipino Sign Language (FSL)
reference material. Do not use the entries below as validated instruction data
until every row has been completed from an authoritative PSL source.

## Completion Rules

- Replace every `TODO` with information copied or carefully transcribed from a
  verified FSL reference.
- Record the source citation for every entry, including title, creator or
  organization, publication or access date, and a stable URL or bibliographic
  reference where available.
- Record `None` or `Not applicable` only when the verified source explicitly
  indicates that no movement is involved.
- Resolve disagreements between sources before collecting training data.
