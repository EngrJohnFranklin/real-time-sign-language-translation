This document is a template for verified Philippine Sign Language (PSL)
reference material. Do not use the entries below as validated instruction data
until every row has been completed from an authoritative PSL source.

## Completion Rules

- Replace every `TODO` with information copied or carefully transcribed from a
  verified PSL reference.
- Record the source citation for every entry, including title, creator or
  organization, publication or access date, and a stable URL or bibliographic
  reference where available.
- Record `None` or `Not applicable` only when the verified source explicitly
